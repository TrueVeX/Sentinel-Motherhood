How to install
  1. Tap the download and open the file.
  2. If asked, allow installs from your browser or Files app (Settings → Allow), then go back.
  3. Tap Install, then Open. Updating? Install the new file over the old one; your data stays.

Windows

Your device

Windows 10 and 11 (64-bit).

Download installer
How to install
  1. Open the downloaded .exe.
  2. If Windows shows “Windows protected your PC”, click More info → Run anyway (the app isn’t code-signed yet).
  3. Follow the installer. Sentinel appears in your Start menu.
🍎

macOS

Your device

Apple Silicon and Intel Macs.

Download for Mac
How to install
  1. Open the .dmg and drag Sentinel into Applications.
  2. The first time, right-click the app → Open → Open (it isn’t Apple-signed yet).
  3. If macOS says the app is damaged, run xattr -cr "/Applications/Sentinel Motherhood.app" in Terminal, then open it again.
🐧

Linux

Your device

Most 64-bit distributions.

Download AppImage Download .deb (Ubuntu, Debian)
How to install
  1. AppImage: make it runnable with chmod +x Sentinel-Motherhood-Linux.AppImage, then double-click it.
  2. .deb: run sudo apt install ./Sentinel-Motherhood-Linux.deb.
