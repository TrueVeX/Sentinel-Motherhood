# Sentinel Motherhood

**Tagline:** Guiding motherhood, nurturing generations.

A responsive Next.js starter for the Sentinel Motherhood digital platform.

## Requirements

- Node.js 20.9 or later
- npm

## Run locally

1. Extract this project folder.
2. Open the folder in VS Code.
3. Open the integrated terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Visit http://localhost:3000

## Current implementation

- Responsive landing page
- Sentinel Motherhood brand identity
- Modern Teal & Ivory palette
- Mobile navigation
- Motherhood journey stage cards
- Introductory support section
- Question input preview

## Important

The question form is currently a frontend demonstration. It does not connect to an AI model and does not provide medical advice. Authentication, database, expert consultation, reminders and the medically reviewed AI knowledge base are future development milestones.

Before production, add privacy controls, accessibility testing, security review and clinician-reviewed content.
